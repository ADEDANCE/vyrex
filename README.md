# Vyrex

Vyrex is a course-selling platform that makes online courses more accessible through flexible payment options.

Instead of paying for a course all at once, learners can access courses through a pay-as-you-go model, helping reduce the risk of scams and making quality education more affordable.

For course creators, Vyrex provides a better way to reach more learners and reduce lost sales caused by high upfront costs.

## Features

* Flexible course payment system
* Pay-as-you-go learning model
* Secure payments with Paystack
* Email notifications with Resend
* Course certificates
* Authentication and user management

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* MongoDB
* Paystack
* Resend
